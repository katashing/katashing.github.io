# 家庭看板

早餐、待办、孩子明日课表的中英文只读网页。

Kindle HTTP 地址：http://43.128.89.2/family/

GitHub Pages 地址：https://katashing.github.io/family/

本目录包含全部前端代码、日程 JSON、字体与菜单参考图片。修改数据后提交并等待 GitHub Pages 发布。
天气按北京时间每日06:00更新为日预报与低–高温；GitHub Pages由weather-client.js请求，HTTP服务器独立更新weather.json，其定时任务需单独部署。农历、两地节日与传统黄历采用独立离线资料。
本页面不收集登录信息，也不提供浏览器写入接口。图片是经用户确认的生成菜单参考图。
