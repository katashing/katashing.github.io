从深圳翰岭院出发。公共交通按地铁／公交分段估算；香港驾车分别经皇岗、莲塘口岸，深圳学校直接到校。按家长2026-10-15最新要求，香港整程通关统一预留15分钟，驾车另预留15分钟路况；数值不代表实时路况或实测排队。单程范围上限超过50分钟标红加粗。

学校地址／电话／官网以香港教育局和学校官方资料为查询依据。新皇岗按2026年10月12日启用后的PTI官方坐标计算到校路网基准；翰岭院到口岸采用历史10分钟＋新接入预留5分钟。口岸内部道路尚未完整映射，出行数据保存依据与限制，不能视作实测整程时间。
