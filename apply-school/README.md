# 学校申请跟踪

GitHub Pages：<https://katashing.github.io/apply-school/>

- 两个表页：已选学校（初始7所）和老师备选（完整24所）。备选选中后仍保留，显示「已选报名」。
- 地区、梯队、报名进度、截止／笔试日期、下次跟进和出行时间直接列在表格中。
- 点击校名或「记录」编辑日期、状态、备注、电话和官网。
- 记录在当前浏览器保存。换设备请导出、导入JSON备份；可导出CSV学校表。
- 截止与11月笔试按2026年；马锦灿1月笔试按2027年、具体日待确认。

## 出行时间

从深圳翰岭院出发。公共交通按地铁／公交分段估算；香港驾车分别经皇岗、莲塘口岸，深圳学校直接到校。页面可调通关排队与驾车路况预留，数值不代表实时路况或实测排队。

学校地址／电话／官网以香港教育局和学校官方资料为查询依据。道路基准由OSRM路网计算，公开来源及校区匹配备注保存在 `travel-data.js`。皇岗口岸2026年10月12日交接后，原道路点估算须导航复核。

## 本地预览

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory .
```

无构建步骤。本目录是网页源码和可发布文件；`scripts/update-travel-routes.py` 默认只查询公开路线，传 `--write` 才改出行数据。

个人跟踪备份及含学生姓名的原图不提交到公共仓库。
